# app/tag_editor.py

- Mutagen の公開 API を使い、MP3 の ID3 と M4A の MP4 タグを編集する。選択された項目、コメント、画像だけを変更する（根拠: app/tag_editor.py:733-853）。
- 編集前のタグ情報と操作履歴を SQLite に記録し、同じファイルに属する履歴から復元する。MP4 の画像や自由形式タグは JSON に符号化し、MP3 のタグは ID3 として保存する（根拠: app/tag_editor.py:309-443,673-731,855-877,965-974）。
- 保存・復元では排他ロックとバージョン確認を行い、事前に同一ディレクトリへ元ファイルのコピーを作成する。書き込み結果を確認し、失敗時はコピーから復旧する（根拠: app/tag_editor.py:243-307,471-537,592-637,879-933）。
- 中断時の復旧用コピーとその状態を SQLite に記録し、画面から復旧または不要なコピーの整理を行う（根拠: app/tag_editor.py:349-443,639-670,977-998）。
