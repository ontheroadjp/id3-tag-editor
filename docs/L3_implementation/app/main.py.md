# app/main.py

- FastAPI がディレクトリ一覧、ファイル情報、音声、アートワークを読み取り専用で提供する（根拠: app/main.py:85-146）。
- ID をルート相対パスとしてデコードし、解決した実パスがルート内にあることと拡張子を検証する（根拠: app/main.py:54-66）。
- 指紋照合ジョブの開始・状態確認・中止、および録音と版の詳細取得を lookup モジュールに委譲する（根拠: app/main.py:23-51）。
- MP3 は ID3、M4A は MP4 タグを読み、音声は Range 対応の FileResponse で返す（根拠: app/main.py:69-82,107-146）。ファイル更新と認証は実装していない。
