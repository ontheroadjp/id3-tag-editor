# app/lookup.py

- `fpcalc` で指紋を生成し、AcoustID から録音 ID、MusicBrainz から録音・リリースを取得する（根拠: app/lookup.py:75-85,96-134）。
- サービス別の頻度制限と一時的エラーの再試行を行い、途中失敗時は取得済み候補と警告を返す（根拠: app/lookup.py:44-72,115-133）。
- 選択された版の曲情報、ディスク内曲数と Cover Art Archive の画像 URL を返す（根拠: app/lookup.py:137-152）。
- ジョブは単一ワーカーとメモリ上の状態で管理し、新規ジョブまたは操作によって中止可能。プロセス再起動後には残らない（根拠: app/lookup.py:20-28,155-206）。
