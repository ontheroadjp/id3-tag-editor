# 実装仕様

## 現状

ローカル向け読み取り専用画面で、フォルダ単位の MP3・M4A 一覧、既存タグと画像の表示、再生・シークを提供する（根拠: app/main.py:85-146、app/static/app.js:63-127）。

音声指紋で AcoustID と MusicBrainz を照合し、言語・アルバム・版を選んで取得タグと既存タグを比較する。照合ジョブはメモリ内に保持され、後から中止可能（根拠: app/lookup.py:75-206、app/static/app.js:148-362）。

相対パスを符号化した ID を受け取り、実パスが音楽ディレクトリ内か検証する（根拠: app/main.py:54-66）。Compose は音楽ディレクトリを読み取り専用でマウントする（根拠: compose.yaml:9-15）。タグ更新や認証は実装されていない。
