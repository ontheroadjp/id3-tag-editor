# 実装仕様

## 現状

ローカル画面で MP3・M4A の閲覧、再生、タグとアートワークの比較、項目を選択した保存とリセットを提供する。画像の選択と既存画像はタグ比較表の末尾に表示する（根拠: app/main.py:473-559、app/static/app.js:225-399,450-501,767-772）。

曲名とコメント以外の入力値と画像を名前付きプリセットとして保存・読み出し・削除できる。読み出しは編集画面への反映であり、音楽ファイルへの保存は別操作である（根拠: app/main.py:74-166、app/static/app.js:40-124）。

音声指紋から候補を取得し、リリースを選ぶ。照合ジョブはメモリ内に保持され中止できる（根拠: app/lookup.py:75-212、app/static/app.js:831-1050）。

Mutagen でタグを読み書きし、SQLite に編集前のタグと操作履歴を記録する。書き込み前に音楽ファイルをコピーし、失敗時と中断時の復旧を支援する（根拠: app/tag_editor.py:309-443,471-670,716-974）。

書き込み API はローカル Host・Origin と有効化設定を検証する。Compose の音楽ディレクトリは既定で読み取り専用である（根拠: app/main.py:112-119,270-276、compose.yaml:5-17）。
