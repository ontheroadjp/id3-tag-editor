# データベース

SQLite の `backups` 表は連番 ID、ファイル ID、日時、保存・復元の種別、復元元、対象項目、タグのスナップショット、結果および復旧コピーの状態を保持する（根拠: app/tag_editor.py:312-348）。履歴はファイル ID により絞り込み、復元時は現在のタグも新たな履歴として記録する（根拠: app/tag_editor.py:355-380,879-894,965-974）。テーブルと不足列は起動時に作成する（根拠: app/tag_editor.py:315-348）。

別の `presets.sqlite3` の `presets` 表は名前を主キーとしてタグと画像を JSON で保存する。初回アクセス時に表を作成する（根拠: app/main.py:122-145）。
